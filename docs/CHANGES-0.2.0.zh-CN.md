# PDF view 0.2.0

- 顶部工具栏改为矢量线条图标，参考 Edge 的分组、留白和配色，仅“绘制”保留文字。
- 增加按钮悬停提示、快捷键说明、悬停与选中状态、画笔和荧光笔颜色指示。
- 窗口标题固定为 PDF view，文件名在标签页显示。安装程序、快捷方式和版本信息同步更新。
- 页面导航与缩放居中，搜索、保存和全屏靠右；较窄窗口自动分为两行。
- 保存按钮保存本机批注，继续支持自动保存；更新沿用原来的数据目录。

验证：Windows x64 交叉编译；17 项核心测试；Wine 中实际 Windows 程序的 PDF 渲染、字体公式样例、鼠标绘制、整笔橡皮、撤销重做、自动保存、搜索、多标签和旋转；通过原生 SetWindowPos 检查 1280 与 780 像素窗口的控件边界，并查看实际截图。真实 Windows 触控和第 11 代 i5 性能尚未实机验证。
