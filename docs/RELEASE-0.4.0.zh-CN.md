# PDF view 0.4.0

- 软件内打开 PDF、DOC、DOCX。DOC/DOCX 需要已安装桌面版 Microsoft Word 或兼容 WPS，默认优先 Microsoft Word。
- 默认原生阅读：Word/WPS 直接排版并提供页面绘图命令，阅读器按需绘制到页面，不生成中间 PDF。
- 原生阅读也支持现有画笔、荧光笔、整笔橡皮、撤销重做和本地自动保存。原文档不变，批注不写入 DOC/DOCX。
- 可在设置中显式选择 PDF 兼容阅读：本机转换后仍在软件内打开；两种模式的批注分别保存，避免不同分页间错位。
- 顶部问号改为矢量齿轮设置。可调整打开文档自动展开侧边栏、恢复会话、滚动时虚化等级、滑动灵敏度、Word 引擎和快捷键。
- 设置自动保存到本机；快捷键支持重新绑定、清除、恢复默认和冲突检查。

Windows 10 1809+ / Windows 11，x64。原生 Word 的字体和公式依赖本机 Office 与字体/旧公式组件；无法保证损坏文档或缺少字体、MathType 等组件时完全还原。原生 Word 查找目前按匹配页定位。

验证包含原有核心测试、设置存取与冲突检查、设置界面操作、以及使用模拟 Office 自动化服务器和真实页面绘图数据的原生渲染/批注持久化回归。测试不代表已在真实 Microsoft Word/WPS 或目标触屏硬件上验收全部公式兼容性与触控性能。
