# PDF view 0.6.3 使用说明

适用 Windows 10 1809 或更新版本，64 位。从桌面打开 PDF view。

## 功能教程

点击右上角齿轮 → 功能教程 → 打开教程并练习。内置六页离线 PDF，前三页介绍阅读与触控、批注工具、保存与 Word 设置，后三页提供数学、物理、化学公式和矢量图形练习。

示例圆圈、箭头、手写公式和旧高亮是可编辑批注，可用现有橡皮擦除，再用撤销恢复。可以继续添加自己的笔记；按 Ctrl+S 保存批注，切换或关闭文档时记住阅读位置，重新进入教程不会覆盖自己的练习。教程本身不需要安装 Office。

## 打开文档

点击文件夹图标、按 Ctrl+O 或拖入 PDF、DOC、DOCX。支持多个标签页。
DOC/DOCX 需安装桌面版 Microsoft Word 或兼容 WPS Office；Word/WPS 创建的标准 DOC/DOCX 均按所选排版引擎处理。推荐 Microsoft Word。

齿轮设置的 Word / WPS 页可选择：
- 原生阅读（默认）：Word/WPS 只读加载文档，直接提供页面绘图数据，不生成中间 PDF。仍在本软件内阅读和使用画笔。
- PDF 兼容阅读：显式选择后，在本机转换成 PDF 并在本软件内阅读。转换在后台运行，可关闭标签页取消，结果缓存后可再次打开。

两种模式都提供现有画笔、旧批注显示、整笔橡皮、撤销重做和手动保存；原 DOC/DOCX 不变。转换模式与原生模式使用独立批注身份。修改原文档后按新文档识别，避免旧批注错位。

数学公式、化学结构、字体和分页由本机 Office 排版处理。需要原字体及旧公式对象所需组件；无法修复文档本身损坏或保证缺少组件时不乱码。共享自动化窗口的 WPS 版本在已有其他文档打开时会拒绝接管，避免关闭或隐藏你的文档，可改用 Word。部分 WPS 版本没有原生页面接口，可手动选择 PDF 兼容阅读，不会偷偷自动转换。

## 阅读与批注

左栏支持目录与缩略图。顶部可跳页、缩放、适应宽度、旋转。Ctrl+F 查找，F3 下一个结果，F11 全屏；原生 Word 的查找按匹配页定位。Ctrl+Shift+C 复制本页文字。

“画笔”和“橡皮”互斥，点击哪一个就只启用该工具；再次点击当前工具回到阅读。鼠标、手指均可使用；双指移动和缩放，单指转双指会取消尚未提交的笔迹。画笔旁的箭头打开颜色与粗细面板，所有文档共用并记忆上次颜色和手动笔宽。Ctrl+Z 撤销、Ctrl+Y 重做。荧光笔不再提供新建入口，旧高亮继续显示、擦除和撤销。

在“设置 → 画笔与校准”可开启自动屏幕线宽，并设定每日重置线宽，范围为 0.1–10 mm，初始值为 2 mm。开启时，新写笔迹会按页面缩放换算，当天手动调整的粗细优先。北京时间次日 00:00 后的下一笔恢复为设定的重置线宽。关闭自动屏幕线宽后，始终使用记忆的文档笔宽。

要求实体尺测量准确时，请在该显示器上打开“校准屏幕尺寸”，用尺测量两端刻度之间的线段长度，输入实际毫米数，再保存设置。程序按显示器与当前分辨率保存校准；换显示器或分辨率后需单独校准。也可选当前分辨率或匹配的 1080p、1440p、2160p 预设并输入屏幕对角线英寸。未手动校准时优先使用系统报告的屏幕物理尺寸，缺失时按 Windows DPI 估算，物理精度受屏幕像素间距和测量误差限制。

点击扫把后，在窗口中央选择清除当前视图、当前页、全文笔迹或取消。跨出窗口的线会保留窗口外的部分，一次撤销可恢复。灰色边缘与页间都可书写，按落笔时的邻近页归属。未保存的标签名带星号，关闭时选择保存、放弃或取消。

清除弹窗打开期间，应用窗口的工具栏、侧栏和文档区都会虚化。可在「设置 → 界面外观」选择偏白或偏灰，并调节毛玻璃透明度。透明度越高，模糊后的背景越明显。

滚轮支持惯性，底部水平滚动条可在放大后左右移动。缩放上限 1600%。通过文件夹或拖放打开 PNG、JPEG、BMP、TIFF 和 GIF，GIF 显示首帧，多页 TIFF 可翻页。WebP 需要 Windows 已安装相应解码器。

## 设置

点击右上角齿轮或默认 Ctrl+, 打开设置：
- 打开文档时自动展开侧边栏；是否在启动时恢复文档。
- 滚动时虚化等级：关闭、轻微、中等、较高，控制交互期间的临时预览质量。已有高清缓存可继续使用，停止滚动后恢复清晰，不永久降低文档质量。
- 滑动灵敏度：0.25×—3×，影响滚轮和阅读拖动，默认 1×。
- Word 原生/PDF 兼容打开方式、排版引擎，下次打开文档时生效。
- 快捷键：选择功能，在输入框按组合键，再点击“绑定”。支持清除、恢复默认，冲突和系统保留按键会提示。

点击“保存”生效并写入本机。点击“取消”不应用修改。

## 数据与限制

设置位于 %LOCALAPPDATA%\PaperView\settings.txt；批注与阅读位置位于 annotations 子目录。关闭软件后可备份整个 PaperView 数据目录。卸载保留数据。
原文档不变，批注仅在软件内保留；不提供带批注文件导出和打印。扫描图片不提供 OCR。安装包未签名。

已检查核心逻辑、设置和使用模拟 Office 服务器提供真实页面绘图数据的原生渲染与批注流程。真实 Word/WPS 排版与触控性能仍需在用户设备上验收。

维护与排版检查：源码中的 `tests/generate_office_fixtures.py` 可生成含 OMML 公式的 DOCX 样例。在装有 Word 的 Windows 上可运行 `PaperView.exe --self-test 样例.docx 输出目录`，生成页面位图与报告，辅助检查本机公式排版；这不替代真实文档目视验收。
