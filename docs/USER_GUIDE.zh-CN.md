# PDF view 0.3.0 使用说明

系统要求：Windows 10 1809 或更新版本，64 位。运行安装程序后从桌面打开 PDF view。

打开：点击文件夹图标或 Ctrl+O，可选择多个 PDF；也可将文件拖入窗口。
目录：左栏可切换目录与缩略图。按钮以矢量图标显示，悬停可查看用途和快捷键；顶部可跳页、缩放、适应宽度和旋转；Ctrl+F 搜索，F3 下一个结果，F11 全屏。
绘制：“绘制”按钮直接开启或关闭书写。开启后鼠标、手指均可写画；旁边箭头打开 30 色圆形色块面板；点击色块后可继续调整粗细滑块，曲线实时预览效果。按 Esc 或点击外部关闭面板。双指用于移动和缩放，单指转双指时取消尚未提交的笔迹。
批注：提供画笔、荧光笔、整笔橡皮、撤销 Ctrl+Z、重做 Ctrl+Y。
保存：批注和阅读位置自动保存到 %LOCALAPPDATA%\PaperView。原 PDF 不变。没有打印和带批注 PDF 导出功能。扫描件可阅读批注，不提供 OCR。
相同文件内容按 SHA-256 识别，因此移动或重命名文件仍可找到批注。修改 PDF 内容会被识别为新文档。
备份：关闭软件后备份上述 PaperView 数据目录；卸载保留批注，跨电脑使用需要自行复制数据目录。

已验证：核心逻辑测试、Windows 程序在 Wine 下的 PDF 渲染、公式字体样例、批注存取、取消任务等测试。真实 Windows 触控和第 11 代 i5 性能尚未实机验证；损坏文件或缺失字体的 PDF 无法保证完全正确显示。
