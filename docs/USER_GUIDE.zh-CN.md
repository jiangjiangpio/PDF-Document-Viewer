# PDF view 0.4.0 使用说明

适用 Windows 10 1809 或更新版本，64 位。从桌面打开 PDF view。

## 打开文档

点击文件夹图标、按 Ctrl+O 或拖入 PDF、DOC、DOCX。支持多个标签页。
DOC/DOCX 需安装桌面版 Microsoft Word 或兼容 WPS Office；Word/WPS 创建的标准 DOC/DOCX 均按所选排版引擎处理。推荐 Microsoft Word。

齿轮设置的 Word / WPS 页可选择：
- 原生阅读（默认）：Word/WPS 只读加载文档，直接提供页面绘图数据，不生成中间 PDF。仍在本软件内阅读和使用画笔。
- PDF 兼容阅读：显式选择后，在本机转换成 PDF 并在本软件内阅读。转换在后台运行，可关闭标签页取消，结果缓存后可再次打开。

两种模式都提供现有画笔、荧光笔、整笔橡皮、撤销重做和本机自动保存；原 DOC/DOCX 不变。转换模式与原生模式使用独立批注身份。修改原文档后按新文档识别，避免旧批注错位。

数学公式、化学结构、字体和分页由本机 Office 排版处理。需要原字体及旧公式对象所需组件；无法修复文档本身损坏或保证缺少组件时不乱码。部分 WPS 版本没有原生页面接口，可手动选择 PDF 兼容阅读，不会偷偷自动转换。

## 阅读与批注

左栏支持目录与缩略图。顶部可跳页、缩放、适应宽度、旋转。Ctrl+F 查找，F3 下一个结果，F11 全屏；原生 Word 的查找按匹配页定位。Ctrl+Shift+C 复制本页文字。

“绘制”按钮直接开启/关闭书写，鼠标、手指均可使用；双指移动和缩放，单指转双指会取消尚未提交的笔迹。箭头打开圆形色块与粗细滑块面板。Ctrl+Z 撤销、Ctrl+Y 重做。

## 设置

点击右上角齿轮或默认 Ctrl+, 打开设置：
- 打开文档时自动展开侧边栏；是否在启动时恢复文档。
- 滚动时虚化等级：关闭、轻微、中等、较高，控制交互期间的临时预览质量。已有高清缓存可继续使用，停止滚动后恢复清晰，不永久降低文档质量。
- 滑动灵敏度：0.25×—3×，影响滚轮和阅读拖动，默认 1×。
- Word 原生/PDF 兼容打开方式、排版引擎，下次打开文档时生效。
- 快捷键：选择功能，在输入框按组合键，再点击“绑定”。支持清除、恢复默认，冲突和系统保留按键会提示。

点击“保存”生效并写入本机。点击“取消”不应用修改。

## 数据与限制

设置位于 %LOCALAPPDATA%\PaperView\settings.txt；批注与阅读位置位于 annotations 子目录。关闭软件后可备份整个 PaperView 数据目录。卸载保留数据。
原文档不变，批注仅在软件内保留；不提供带批注文件导出和打印。扫描图片不提供 OCR。安装包未签名。

已检查核心逻辑、设置和使用模拟 Office 服务器提供真实页面绘图数据的原生渲染与批注流程。真实 Word/WPS 排版与触控性能仍需在用户设备上验收。

维护与排版检查：源码中的 `tests/generate_office_fixtures.py` 可生成含 OMML 公式的 DOCX 样例。在装有 Word 的 Windows 上可运行 `PaperView.exe --self-test 样例.docx 输出目录`，生成页面位图与报告，辅助检查本机公式排版；这不替代真实文档目视验收。
